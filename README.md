# game-project

Учебный проект по курсу ОПД: **«Avengers project»** — аркадный вертикальный шутер на pygame.

## Что это вообще такое

Космический шутер с видом сверху: управляешь кораблём, отбиваешься от волн врагов, астероидов и мин, собираешь пауэрапы и скрап, а в конце ждут боссы. Экран 800×800, всё рисуется спрайтами, звук синтезируется на лету, музыка — mp3-треки.

Что внутри:

- **Волны врагов** — несколько типов кораблей с разными паттернами движения (кривые Безье), щитами и стрельбой; между волнами экран Stage Clear с возможность докупить апгрейды.
- **Астероиды и мины** — астероиды крутятся, дают очки и иногда роняют контейнеры; мины взрываются при контакте.
- **Боссы** — несколько боссов с разными механиками (щит-орбы, фазы входа), у финального — отдельный саундтрек.
- **Комбо-система** — множитель очков растёт с ×1.0 до ×4.0 за серию убийств (окно ~2.5 с), над врагами всплывает «+N / 1.4x Combo!».
- **Пауэрапы** — падают с врагов (35%) и контейнеров: `[W]` оружие, `[S]` щит, `[$]` скрап, `[D]` двойной урон, `[T]` замедление времени, `[M]` магнит.
- **Скрап, ангар и казино** — за скрап покупаются апгрейды в ангаре, можно спустить всё в слот-машине (комбинации символов, джекпот).
- **Лидерборд и разблокировки** — рекорды и открытые элементы хранятся локально (`highscores.json`, `unlocks.json`).

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение (2D) |
| SPACE (удерживать) | лазеры |
| **SHIFT** | **дэш** — рывок ×3 скорости в сторону движения, ~1 с перезарядка; во время рывка корабль «фазирует» сквозь атаки |
| ESC | пауза |
| M | музыка вкл/выкл |
| Мышь | меню, ангар, казино |

## Как запустить

Нужен Python 3.8+ и pygame.

```bash
git clone https://github.com/mevych/game-project
cd game-project
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install pygame
python main.py
```

> **Нюанс для новых Python (3.13/3.14):** если `python main.py` падает с `pygame.mixer not available`, значит pygame собрался без аудиомодуля. Лечится заменой на pygame-ce — это drop-in форк с тем же `import pygame`:
> ```bash
> pip install pygame-ce
> ```

## Структура кода

| Файл | Что там |
|---|---|
| `main.py` | игровой цикл, state machine, переключение музыки |
| `game.py` | класс `Game`: волны, коллизии, HUD, все экраны (меню/ангар/казино/инструкции), магазин |
| `entities.py` | `Player`, враги, `BaseBoss` и боссы, астероиды, мины, пауэрапы, лазеры |
| `effects.py` | частицы, всплывающий текст, тряска камеры |
| `sound.py` | `SoundManager`: загрузка wav + fallback-синтез недостающих звуков |
| `constants.py` | размеры экрана, FPS, палитра цветов |
| `leaderboard.py` | рекорды и разблокировки |

## Форк: дэш и хит-джус

В этом форке добавлены две фичи (детали и ревью — в [PR #21](https://github.com/mevych/game-project/pull/21)):

- **Дэш на Shift** — рывок ×3 на 8 кадров с кулдауном ~1 с, i-frames на время рывка, шлейф из затухающих копий спрайта, синтезированный звук и индикатор перезарядки в HUD.
- **Хит-джус** — белая вспышка врагов/астероидов/боссов при попадании лазера и hitstop (короткий стоп-кадр мира) на убийстве: 3 кадра за врага, 2 за астероид, 5 за босса.
